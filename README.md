# Yelena · 个人小程序

一个像素风个人主页小程序，把「我是谁、我经历过什么、我喜欢什么、我想去哪」整理成可以点开的东西。

原生微信小程序（无框架）+ 微信云开发。所有视觉素材（字体子集、图标、插画、风景、画布背景）**都由脚本生成**，以 base64 内嵌在 wxss 里，没有任何外部图片依赖。

## 功能

底部 4 个 tab：**首页 / 待办 / 财富 / 关于我**，其余页面从首页的入口卡进入。

| 页面 | 内容 | 能在小程序里改吗 |
|---|---|---|
| 首页 | 头像、昵称、签名、8 个功能入口 | 昵称签名跟「关于我」联动 |
| 关于我 | 像素角色卡、属性面板、基本信息、自我介绍 | ✅ 点「修改我的资料」 |
| 个人经历 | 彩色年份标签的时间轴，自动按年份排序 | ✅ 点卡片改 / 删 |
| 兴趣爱好 | 图标卡片网格，7 种像素图标可选 | ✅ 点卡片改 / 删 |
| 想学的技能 | 带进度条和平均值的技能列表 | ✅ 滑块调进度 |
| 人际交往 | 可缩放的关系图画布 + 性格标签 + 联系方式 | ✅ 拖拽、连线、自定义分类 |
| 未来展望 | 三组大图卡片，5 种像素风景或自定义照片 | ✅ 长按改 / 删 |
| 愿望详情 | 点愿望卡片进入，看大图和完整内容 | ✅ 修改 / 删除 |
| 待办事项 | 进度条、分组、勾选完成 | ✅ 加 / 改 / 删 |
| 财富 | 总资产、账户占比条、金额隐藏 | ✅ 加 / 改 / 删 |
| 留言板 | 云端留言、点赞、回复 | ⚠️ 首版隐藏入口（见下） |

## 几个做得比较用心的点

**关系图画布**（`pages/social`）

- 双指缩放（以两指中点为锚点）、单指平移、按住名片拖动
- 最多 5 块画布翻页，新名片自动找空位、不重叠
- 双击任意连线写「这段关系是什么」
- 自定义分类：内置朋友/同学/家人/同事，可以自己加「室友」「网友」……颜色由脚本按色相距离算出，不会撞色
- 删分类会连带删掉里面的人，但**长按删完 5 秒内可以撤销**

**删除都能撤销**（`components/undo-bar`）

全站 9 个删除点统一：删掉后底部弹出横条，5 秒内点「撤销」原样恢复。人际页的连带删除（分类、整块画布）靠整份数据快照还原。删愿望时图片文件会等撤销窗口过了才真正删掉，避免「撤销回来是个破图」。

**文字自动聚焦**

点「修改」进入编辑态时，输入框自动获得焦点、键盘直接弹出。iOS 上同一次 `setData` 里同时挂载输入框和设置 `focus` 会失效，所以统一延迟 120ms 再置 `true`。

## 本地运行

1. 用**微信开发者工具**导入这个目录
2. 在 `config.js` 里填上你自己的云开发环境 ID：

   ```js
   module.exports = {
     ENV_ID: '你的环境ID'
   }
   ```

   不填也能跑——只是留言板用不了，其余页面全本地存储。
3. 如果要用留言板，在「云开发」控制台里把 `cloudfunctions/` 下 5 个函数逐个**上传并部署**
4. 编译

> `appid` 在 `project.config.json` 里，换成你自己的即可。

## 数据都存在哪

**没有账号体系，也没有服务端用户表。** 除了留言板，所有内容都存在**手机本地缓存**里：

| 缓存 key | 内容 |
|---|---|
| `yelena_profile` / `yelena_stats` | 昵称、签名、标签、城市、MBTI、自我介绍、属性条 |
| `yelena_experience` | 个人经历 |
| `yelena_hobbies` | 兴趣爱好 |
| `yelena_skills` | 想学的技能 |
| `yelena_future` | 未来展望 |
| `yelena_boards` / `yelena_cats` / `yelena_view` | 关系图画布、自定义分类、缩放位置 |
| `yelena_social` | 性格标签、交友偏好、微信号 |
| `yelena_todos` | 待办 |
| `yelena_wealth` / `yelena_wealth_hidden` | 账户、金额隐藏开关 |

所以：**换手机、删掉小程序，数据就没了**（这也是它不用备案成"网络服务"的原因）。

`data/content.js` 只是**出厂默认值**——第一次打开时灌进缓存，之后改它不会影响已经打开过的小程序。想恢复默认，把小程序删掉重新进。

留言板是唯一的云端数据，存在云开发数据库 `messages` 集合里，客户端不直连数据库，全部走云函数。

## 关于留言板

首版**没有入口**（tabBar 里没有「留言」）。原因：个人主体小程序不能申请「社交」类服务类目，而留言板属于社区/论坛性质，挂在「工具-效率」下提审有被判类目不符的风险。

代码、云函数、数据库都完整保留着。`pages/guestbook/guestbook.js` 文件开头写了 4 步恢复方法。

## 素材

所有像素图都是脚本用 [Pillow](https://python-pillow.org/) 画的，生成后转 base64 内嵌进 wxss，所以小程序里没有任何 `images/` 之外的图片文件，也不依赖网络加载。

字体是用 [fontTools](https://github.com/fonttools/fonttools) 从开源中文字体里裁的 3900 字子集（常用字），转成 woff2 后 base64 内嵌。
